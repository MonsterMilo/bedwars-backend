# Card fonts

Used by `cards.js` to draw the Discord bot's image cards in the website's themes.

- Jersey 10, Silkscreen, Manrope, Anton, Courier Prime, Caveat, Playfair Display,
  EB Garamond, Chakra Petch, Sora, Grenze Gotisch, Grenze, Crimson Pro: from Google Fonts, under the SIL Open Font
  License 1.1 (https://openfontlicense.org).
- DejaVu Sans Bold (symbols such as ✫ ✪ ⚑ ⚠): DejaVu Fonts License (Bitstream
  Vera derivative, free to redistribute), https://dejavu-fonts.github.io/License.html.
